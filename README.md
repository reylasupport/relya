# Relya

A personal assistant for the administrative side of life.

Relya turns a receipt, a bill or a screenshot of an appointment into
something it remembers for you: the date, the deadline, the amount, and a
reminder before it matters. Built with Flutter and Supabase.

**Status:** in development, not yet published.

## Why this domain

`relya.is-local.org` is used for one thing only: an inbound-only email
address per user, so someone can forward a bill to the app instead of
retyping it. Mail is received, never sent.
